# Pocket Arcade

A small, self-contained browser arcade with five games:

- **Snake**: eat, grow and avoid crashing.
- **Memory Match**: find all eight matching pairs.
- **Tic-Tac-Toe**: play as X against the computer.
- **Folded Halls**: explore an unusual first-person maze.
- **2048**: merge tiles to reach 2048.

## Play

Open `index.html` in a modern browser, or visit the GitHub Pages site if enabled for this repository. No account, build step or package installation is required.

Keyboard controls are shown in each game's hint. On touch devices, Snake and 2048 support swipes; Snake also has on-screen direction buttons. Best scores are stored locally in the browser where supported.

## Development

The project is intentionally dependency-free: the games, styles and application logic are contained in `index.html`. Edit that file and refresh the page to test changes.
